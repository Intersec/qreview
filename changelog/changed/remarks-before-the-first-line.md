- A remark that belongs to no line stands before the first line of the file,
  inside the code, the way Gerrit puts one there. The band above the diff took
  the top of every screen, on every file, whether it held anything or not.
- **Comment on the change** is gone. Gerrit has no useful place for a remark
  about a whole change, and the convention is to write it on the commit
  message instead: it is a file like any other, it takes replies, and a
  session reads it first. The button says *Comment on the change* when the
  commit message is the file you are on.
